# QA Product Lab API

Base URL (local): `http://localhost:4000`

All product endpoints accept and return JSON. Error responses use a stable envelope so automated tests can assert on `error.code`.

## Product resource

```json
{
  "id": "3b8c2d5e-4a21-4f0c-9d77-2c1a6f4e8b90",
  "name": "USB Keyboard",
  "description": "Wired keyboard for the lab",
  "price": "29.99",
  "quantity": 10,
  "created_at": "2026-10-13T19:20:00.000Z",
  "updated_at": "2026-10-13T19:20:00.000Z"
}
```

| Field | Type | Notes |
| --- | --- | --- |
| `id` | UUID string | Generated by the database |
| `name` | string | 1–150 characters after trim |
| `description` | string or `null` | Optional |
| `price` | string | `NUMERIC(12,2)` serialized with two decimal places |
| `quantity` | integer | 0 or greater |
| `created_at` | ISO-8601 timestamp | UTC |
| `updated_at` | ISO-8601 timestamp | UTC |

GET `/api/products` returns a JSON array of these objects, ordered by `created_at` ascending, then `id` ascending.

## Validation rules

Request bodies for POST and PUT must be JSON objects with only these fields:

- `name` (required)
- `description` (optional)
- `price` (required)
- `quantity` (required)

PUT is a full replacement. All required fields must be sent on every update.

| Rule | Valid example | Invalid example |
| --- | --- | --- |
| `name` is a non-empty string after trim | `"Keyboard"` | `""`, `"   "`, missing, `123` |
| `name` length ≤ 150 | 150 characters | 151 characters |
| `description` is a string, `null`, or omitted | `"Lab use"`, `null` | `true`, `12` |
| `price` is a finite JSON number `> 0` | `0.01`, `29.99` | `0`, `-1`, `"9.99"` |
| `price` has at most 2 decimal places | `19.9` | `1.239` |
| `price` is at most `9999999999.99` | `100` | `10000000000` |
| `quantity` is an integer `≥ 0` | `0`, `10` | `-1`, `1.5`, `"2"` |
| No unknown fields | `{ name, price, quantity }` | `{ ..., "sku": "A" }` |
| Path `id` is a UUID | `11111111-1111-4111-8111-111111111111` | `not-a-uuid` |
| Body is valid JSON | `{ "name": "A", ... }` | `{"name":` |

## Error envelope

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request validation failed.",
    "details": [
      {
        "field": "price",
        "code": "MIN",
        "message": "Price must be greater than 0."
      }
    ]
  }
}
```

| HTTP | `error.code` | When |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | Body fails field rules, including unknown fields |
| 400 | `INVALID_JSON` | Malformed JSON |
| 400 | `INVALID_UUID` | `:id` is not a UUID |
| 400 | `CONSTRAINT_VIOLATION` | Database check constraint rejected the row |
| 404 | `PRODUCT_NOT_FOUND` | UUID is valid but no product exists |
| 409 | `CONFLICT` | Unique/constraint conflict (reserved) |
| 500 | `DATABASE_ERROR` | Unexpected database failure |
| 500 | `INTERNAL_ERROR` | Unexpected server failure |

Failed operations never return 2xx.

## `POST /api/products`

Creates a product.

### Example request

```http
POST /api/products
Content-Type: application/json

{
  "name": "USB Keyboard",
  "description": "Wired keyboard for the lab",
  "price": 29.99,
  "quantity": 10
}
```

`description` may be omitted or `null`.

### Success: 201 Created

```json
{
  "id": "3b8c2d5e-4a21-4f0c-9d77-2c1a6f4e8b90",
  "name": "USB Keyboard",
  "description": "Wired keyboard for the lab",
  "price": "29.99",
  "quantity": 10,
  "created_at": "2026-10-13T19:20:00.000Z",
  "updated_at": "2026-10-13T19:20:00.000Z"
}
```

### Error examples

Missing fields (400 `VALIDATION_ERROR`):

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request validation failed.",
    "details": [
      { "field": "name", "code": "REQUIRED", "message": "Name is required." },
      { "field": "price", "code": "REQUIRED", "message": "Price is required." },
      { "field": "quantity", "code": "REQUIRED", "message": "Quantity is required." }
    ]
  }
}
```

Malformed JSON (400 `INVALID_JSON`):

```json
{
  "error": {
    "code": "INVALID_JSON",
    "message": "Malformed JSON in request body.",
    "details": []
  }
}
```

## `PUT /api/products/:id`

Replaces an existing product. `:id` must be a UUID. The body must include all required fields.

### Example request

```http
PUT /api/products/3b8c2d5e-4a21-4f0c-9d77-2c1a6f4e8b90
Content-Type: application/json

{
  "name": "Wireless Keyboard",
  "description": "Updated",
  "price": 39.5,
  "quantity": 4
}
```

### Success: 200 OK

Returns the updated product. `price` in the response is `"39.50"`.

### Errors

- Invalid UUID: 400 `INVALID_UUID`
- Valid UUID, missing row: 404 `PRODUCT_NOT_FOUND`
- Invalid body: 400 `VALIDATION_ERROR`

```json
{
  "error": {
    "code": "PRODUCT_NOT_FOUND",
    "message": "Product not found.",
    "details": []
  }
}
```

---

## `DELETE /api/products/:id`

Deletes an existing product.

### Example request

```http
DELETE /api/products/3b8c2d5e-4a21-4f0c-9d77-2c1a6f4e8b90
```

### Success: 204 No Content

Empty body.

### Errors

- Invalid UUID: 400 `INVALID_UUID`
- Valid UUID, missing row: 404 `PRODUCT_NOT_FOUND`
